# TheirStack — Greenhouse ATS Job Postings (data source)

- **Dataset URL:** https://theirstack.com/en/job-posting-api/data-source/greenhouse
  (parent product: https://theirstack.com/en/jobs-dataset)
- **Platform:** TheirStack (commercial vendor site — NOT a dataset repository)
- **ATS provider(s):** Greenhouse specifically here, but the product is tagged across many
  ATS sources. Postings carry their original source URL, so ATS/career-board domain IS
  derivable from records — *if* you can access the data.
- **Approx size:** 210M job postings, 12M companies, 346,000+ sources, 195+ countries, since 2021.
- **Access:** web page is public; the **data is a PAID API/SaaS** — no free bulk download or
  free company list shown.
- **Date checked:** 2026-06-23
- **License:** Proprietary / commercial ToS
- **Gated:** YES — this is a LEAD, not retrievable data.

## One-line description
Paid job-postings API that lets you filter by ATS data source (e.g. Greenhouse) and returns
the posting's original source URL — i.e. ATS-tagged at the record level, but gated behind a
paid account. Has per-ATS landing pages (greenhouse shown; lever/ashby/workday/etc. exist by
swapping the URL slug).

## Verdict for HeadStart
Strong LEAD if a budget/trial is acceptable: the only source found that explicitly slices job
postings by ATS provider AND exposes the source career-board URL. Free tier scope unknown.
Not downloadable as a static dataset.

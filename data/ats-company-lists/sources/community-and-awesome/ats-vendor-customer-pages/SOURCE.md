- **ATS provider(s):** Ashby, Lever, Greenhouse, SmartRecruiters, Teamtailor, Keka (+ Darwinbox/Keka enterprise names via web search, flagged HRMS).
- **Approx count captured:** Ashby ~100, Keka ~73, Teamtailor ~36, SmartRecruiters ~36, Lever ~29, Greenhouse ~22 named companies. (Vendors claim far more — Lever "3,000+", Keka "12,500+ orgs" — but only these are NAMED on the pages.) Recruitee /customers page 404s.
- **Access:** web, free, no login.
- **License / terms:** Vendor marketing content; company names are factual. No redistribution license; use as high-confidence seed list.
- **Description:** Companies the ATS vendor publicly names as customers (logo walls, case studies, testimonials, customer-video spotlights). Slug is almost always the company name lowercased; verify against the board API before scraping. Ashby's page is unusually rich (~100 names) and skews tech/startup — directly on-target for HeadStart.

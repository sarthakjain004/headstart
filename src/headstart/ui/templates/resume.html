Click a block to edit it, or pick one from the Outline in the panel — that list is how the page is reached without a mouse. Drag the handle to reorder, or Alt + ↑ / ↓; drag an edge to resize.

{# A tablist, not navigation. These four swap panels inside this panel; they go nowhere, so `aria-current="page"` was describing the wrong thing entirely — and it left a screen reader with no idea which panel each button controls, and a keyboard user with four tab stops and no arrow-key traversal. Roving tabindex is set here and maintained by resume_editor.js's showTab. #}
{# `tabindex="0"` on the panel itself: the Checks panel is a single paragraph when nothing is flagged, so without it the panel a tab names can hold nothing focusable and a keyboard user arrives nowhere. #}
